# ZGLTVPN Client

One-click VPN client for Android and Windows (iOS later).

- **Android:** fork of [sing-box-for-android (SFA)](https://github.com/SagerNet/sing-box-for-android), rebranded ZGLTVPN with a one-click login → connect flow.
- **Windows:** Tauri v2 + React/TypeScript app with the official `sing-box.exe` as a sidecar process.
- Builds run on GitHub Actions (this VM cannot build the artifacts).

See [client/README.md](client/README.md) and [docs/client-plan-2026-11-09.md](docs/client-plan-2026-11-09.md) for the plan, the subscription contract, and the sing-box template.
